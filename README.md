# 🍽️ Restaurant & Hotel Management System

A responsive Restaurant & Hotel Management web application developed using **Python, Flask, HTML5, CSS3, Bootstrap 5, JavaScript, and MySQL**.

## 📌 Features

- 🏠 Home Page
- 👤 User Login
- 📝 User Registration
- 🍽️ Restaurant Information
- 🛏️ Room Booking
- 🖼️ Gallery
- 📞 Contact Page
- 👨‍💼 Admin Page
- 📱 Responsive Design

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

### Backend
- Python
- Flask

### Database
- MySQL

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/bedreyashish3-alt/Restaurant-Hotel-Management-System.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open your browser

```
http://127.0.0.1:5000
```
